# ThaiGov Connect

เว็บแอปรวมข่าวสารและสิทธิประโยชน์จากหน่วยงานราชการไทย ในรูปแบบไฟล์ HTML ไฟล์เดียวจบ
รองรับภาษาไทย/อังกฤษ, โหมดสว่าง–มืด และทำงานได้ทันทีโดยไม่ต้องมีเซิร์ฟเวอร์

## 🔗 เว็บไซต์

หลังเปิด GitHub Pages แล้ว จะเข้าได้ที่:

```
https://<ชื่อผู้ใช้ GitHub>.github.io/thaigov-connect/
```

> เว็บทำงานได้เต็มรูปแบบด้วยข้อมูลในตัว ส่วนฟีเจอร์ "ข่าวสด" ต้องรัน Connector server เพิ่ม (ดูด้านล่าง)

## 📁 ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|------|--------|
| `index.html` | หน้าเว็บหลัก (สำเนาของ `ThaiGov-Connect.html`) — GitHub Pages ใช้ไฟล์นี้เป็นหน้าแรก |
| `ThaiGov-Connect.html` | ไฟล์ต้นฉบับ เปิดใช้งานแบบออฟไลน์ได้ |
| `thaigov-live-server.js` | เซิร์ฟเวอร์เสริม ดึงข่าวสดจาก RSS/API หน่วยงานราชการ |
| `package.json` | ตั้งค่าโปรเจกต์ Node |
| `.nojekyll` | บอก GitHub Pages ให้เสิร์ฟไฟล์ตามจริง (ไม่ผ่าน Jekyll) |

## 🚀 วิธีดูข่าวสด (ทางเลือก — รันในเครื่อง)

ฟีเจอร์ข่าวสดต้องการ Node.js 18 ขึ้นไป (ไม่ต้องติดตั้ง dependency ใด ๆ)

```bash
node thaigov-live-server.js
```

จากนั้นเปิดเว็บแล้วกดปุ่มรีเฟรช แอปจะดึงข่าวสดจาก `http://localhost:8787/api/news` อัตโนมัติ

> หมายเหตุ: GitHub Pages เป็นโฮสต์แบบ static จึงรัน Node server ไม่ได้ ฟีเจอร์ข่าวสดจึงใช้ได้เฉพาะตอนรันเซิร์ฟเวอร์ในเครื่องเท่านั้น ส่วนตัวเว็บบน Pages จะแสดงข้อมูลที่ฝังมาในตัว

## 🛠 พัฒนาต่อ

แหล่งข่าวเพิ่ม/แก้ได้ในตัวแปร `SOURCES` ภายใน `thaigov-live-server.js` (รองรับ RSS/Atom ทุกฟีด)
